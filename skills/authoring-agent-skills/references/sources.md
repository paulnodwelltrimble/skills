## Disagreements
MUST vs explain-why (Vercel: forced "MUST use skill" hurt results). Third person vs imperative descriptions (combine them). Scripts by default (Anthropic) vs instructions by default (Codex). Binary vs partial credit. One judge vs one per dimension. Grade outcome vs path (Braintrust and OpenAI also check the path for stateful agents). Undertriggering (skill-creator: be "pushy") vs balance. Auto-updated vs human-gated memory. Tokens vs words for the 5k limit.
